# phased-plan

Write a phased implementation plan for a medium or large task (3+ files, new architecture, several valid approaches) without implementing it. Use on "plan this", "make a plan", "วางแผนก่อนทำ", "break this into phases".

Part of [agent-skills](https://github.com/alinvarat/agent-skills). Install: copy or symlink this folder into `~/.claude/skills/phased-plan`.

Based on [poteto/noodle](https://github.com/poteto/noodle) by Lauren Tan (MIT). See `references/NOTICE.md`.
