# Plan templates
## overview.md
- Goal and intent (2-3 lines)
- Scope in / out
- Constraints and approaches considered (chosen one and why)
- Phase list: number, one-line goal, files, depends-on
- Verification: per phase, a runnable command or observable result
- Skills used per phase
- Risks and open questions

## phase-N.md
- Goal
- Changes: files (max 3) and what changes in each, in prose
- Tests: named cases (max 5)
- Done when: checkable condition
- Depends on: earlier phases
No code blocks. Name types and functions without defining them.
